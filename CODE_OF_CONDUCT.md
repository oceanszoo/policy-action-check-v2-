# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work.
Harassment, personal attacks and discriminatory language are not accepted in issues, pull
requests or any other project space.

To report a problem, contact the maintainer privately through a GitHub security advisory
(Security tab -> Report a vulnerability) and say it is a conduct report. Reports are kept
confidential. The maintainer may remove content and block participants who break this code.
